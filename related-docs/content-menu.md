# テック無尽 2026 コンテンツメニュー

- 対象イベント: テック無尽 2026（2026年11月22日（日）/ 山梨県立図書館 イベントスペース東面）

---

## 1. トラック設計

### 1-1. 会場の物理前提

利用するのは **山梨県立図書館 イベントスペース東面（半面・201㎡・収容177名）の単一空間**。公式情報では「全面を稼働壁で区切った半面を使用し、スライディングウォールでレイアウト変更も一部可能」とされている。

このため「トラック」は**音が遮断された別室3つ**ではなく、**1部屋の中の並行ゾーン**として設計する。帰結:

- 増幅音声（マイク・スピーカー）を出せるのは **ステージの1トラックだけ**。
- 残りは「静かな会話で成立するゾーン」として周囲に配置する。
- ハッカソンが **Webアプリ非同期参加**なのは好都合で、騒音を出さずどのゾーンからでも参加でき、ステージと競合しない。

→ 実態は **「1つの時間割トラック（ステージ）＋2つのゾーン」**。

### 1-2. 3トラックへの割り当て

| トラック | 性質 | 割り当てるコンテンツ |
|---------|------|---------------------|
| **T1 ステージ（発表）** | 時間割・増幅音声あり・全体の軸 | C1 / C2 / C3 / C4 / C7（趣旨説明・結果発表）/ N7 テック無尽ラジオ / C6（クロージング）＋演出 N4・N5、運用 N6 |
| **T2 ブース（展示・頒布・体験）** | 常設ゾーン・静かな会話 | C5 / N1 物販 / N2 make工作 / N3 合同誌その場執筆 |
| **T3 ハンズオン（午後アクティブ）** | 午後に立ち上がる参加ゾーン | C7 ハッカソン・ハンズオン |

設計の肝:

- **午前＝T1ステージ中心の「聞く・知る」、午後＝T3中心の「手を動かす・話す」** へ重心を移す二部構成。
- **ハッカソンは終日常設ではなく、午後の 1〜2 時間ハンズオン**。手を動かす密度を上げ、ダレを防ぐ。
- **クロージング前の「交流」は N7 テック無尽ラジオとして具体化**し、午後に T1 ステージで実施。登壇者をゲストに招き、話の熱が冷めないうちに深堀りする。
- 午後は「**手を動かす人＝T3 ハンズオン**」と「**聴く/お便りで関わる人＝T1 ラジオ**」が並走。ラジオは**ステージ設備を使った“ゆるい公開収録”**で、ハンズオンの BGM 的役割も果たし一体感を生む（増幅音量は作業の妨げにならない範囲に調整）。
- 演出・運用（N4・N5・N6）はステージ付帯機能として T1 に内包。
- 結果発表・クロージングの頃には **T2・T3 は撤収開始**。全員が T1 に集まる導線にして自然に締める。

## 3. コンテンツの説明

### T1 ステージ（発表）

- **C1 オリエンテーション・場づくり** … MC が趣旨と進め方を説明。「聞くだけ参加も歓迎」「自由に回遊してよい」を明示し、初参加者の心理的ハードルを下げて場の空気を整える。
- **C2 コミュニティ紹介** … 各コミュニティの運営メンバーが登壇し、活動内容や雰囲気を紹介。「自分が参加した場合のイメージ」を持てるようにし、後半の会話のきっかけを作る。
- **C3 代読LT（参加者の反応を拾う）** … 受付で配布する QR から、参加者がスマホで「来た理由」「気になる技術」などを投稿。司会がその場でピックアップして代読し、発言が苦手でも一歩関われる体験を提供する。
- **C4 コミュニティLT** … 各コミュニティによる短時間のライトニングトーク。技術解説より「どんな活動・テーマに取り組んでいるか」という“入口”を重視し、交流の話題を増やす。
- **C6 クロージング** … まとめと各コミュニティの今後のイベント情報・参加方法の案内。その場限りで終わらない関係性につなげる。
- **C7 生成AI活用型ハッカソン（趣旨説明・結果発表）** … T1 ではお題発表（午後の入口）と結果発表・人気投票を行う。ハンズオン本体は T3。
- **N7 テック無尽ラジオ（公開トークコーナー）** … 主催＋ラジオパーソナリティ担当が、LT登壇者・コミュニティ代表をゲストに招き、発表内容や活動を深堀りする公開トーク。午後にステージ設備を使った“ゆるい公開収録”として実施し、T3 のハンズオンと並走する。参加者（リスナー）は事前案内された方法で「お便り」（質問・感想）を匿名/ハンドルネームで投稿し、紹介→ゲストが回答。質疑の収集と「前に出て話す」ハードルのさらなる低減を兼ねる。お便りの投稿動線は C3 の仕組み（QR/フォーム）を流用できる。

### T2 ブース（展示・頒布・体験）

- **C5 オープンブース・交流エリア** … 会場外周にテーブルを配置し、コミュニティ・個人・協賛企業が出展。「見るだけ」「立ち寄るだけ」も歓迎し、会話が苦手な人の居場所を作る。事前エントリー制。
- **N1 物販・頒布コーナー** … 技術書典／コミケ的な頒布。出展者の継続的な活動につながる。
- **N2 make・工作コーナー** … 手を動かす体験型コーナー。
- **N3 合同誌 その場執筆** … コミュニティ合同誌のページを当日その場で執筆（絵・一言感想も可）。技術書典など後続イベントへの接続を狙う。

### T3 ハンズオン（午後アクティブ）

- **C7 生成AI活用型ハッカソン（ハンズオン）** … 午後 90分（60〜120分で調整可）の手を動かす枠。Webアプリ経由の非同期参加で、発言せずに参加でき技術レベルを問わない。AIコミュニティを巻き込み一体感を作る。

### 演出・運用（T1 付帯）

- **N4 Claude Code ライブスライド** … 代読LT（C3）のコメントをその場でスライド化する演出。
- **N5 ニコニコ風 弾幕表示** … 代読LT（C3）のコメントを画面に弾幕で流す演出。
- **N6 LT資料 QRコードDL** … LT（C4）資料を QR でいつでもダウンロード可にし、今後の参加につなげる運用改善。
