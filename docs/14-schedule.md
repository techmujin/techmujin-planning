## 14. スケジュール（準備〜当日）

本イベントでは、段階的に企画の解像度を高めながら、関係者を巻き込みつつ準備を進めていく方針としています。

ここでは、開催までの全体スケジュールを「フェーズごと」に整理します。

### 14-1. 全体の進行フェーズ

本イベントは、以下の4つのフェーズに分けて進行します。

#### ■ Phase 1：方向性固め（2〜3月）
イベントの核となるコンセプトと全体像を整理するフェーズです。

- イベント名の決定  
- コンセプト・全体構成の整理  
- 企画書のたたき台作成  
- 声かけ準備（コミュニティ・関係者）  

この段階では、「このイベントは何をするのか」を明確にし、外部に説明できる状態を目指します。

#### ■ Phase 2：関係者巻き込み（4〜6月）
コミュニティ・教育機関・関係者と連携し、イベントの骨格を固めるフェーズです。

- コミュニティ・大学・行政への共有  
- 参加形態（展示・LT等）の仮決定  
- 初期広報の開始  
- 企画全体の微調整  

この段階では、「企画がブレずに外に説明できる状態」を維持しながら、関係者の参加意向を形成していきます。

#### ■ Phase 3：具体準備（7〜9月）
イベントの具体的な内容と当日の運営設計を固めるフェーズです。

- コンテンツ詳細の確定  
- 当日運営・進行設計  
- タイムテーブル案作成  
- 広報強化  

この段階では、「当日の流れが具体的にイメージできる状態」を目指します。

#### ■ Phase 4：直前・本番（10〜11月）
最終調整と本番運営を行うフェーズです。

- 最終調整（会場・機材・導線）  
- リマインド・最終広報  
- 当日運営  
- 振り返り  

この段階では、「迷いなく当日運営ができる状態」を整えます。

### 14-2. 領域ごとの進行

各フェーズにおいて、以下の領域ごとに並行して準備を進めます。

#### ■ 全体設計
- コンセプト・構成の整理  
- イベント全体の一貫性の維持  
- 最終判断・調整  

#### ■ コンテンツ設計
- 各企画の目的整理  
- 当日の進行設計  
- 誰が見ても進行できる状態の整備  

#### ■ コミュニティ連携
- 参加コミュニティへの声かけ  
- 出展・登壇内容の調整  
- 役割分担の明確化  

#### ■ 広報・周知
- 発信内容の設計  
- connpass・SNSでの告知  
- 段階的な情報発信  

#### ■ 会場・当日運営
- 会場条件の確認  
- レイアウト設計  
- 当日の導線・トラブル想定  

これらの領域を横断的に進めることで、企画・広報・運営が分断されないようにします。

### 14-3. スケジュール設計の考え方

本イベントのスケジュールは、単にタスクを消化するのではなく、各フェーズで以下の状態を達成することを重視しています。

- Phase 1：イベントの目的と内容を明確に説明できる  
- Phase 2：関係者と方向性を共有し、参加の見込みが立つ  
- Phase 3：当日の運営イメージが具体化されている  
- Phase 4：迷いなく当日運営ができる  

これにより、準備の進行状況を「状態」で把握しながら、無理のない形でイベントを完成させることを目指します。

### 14-4. 今後の調整について

本スケジュールは現時点での想定であり、参加コミュニティ数やコンテンツの確定状況に応じて柔軟に調整を行います。

各フェーズでの到達状態を基準としながら、現実的な進行を維持できるよう適宜見直しを行います。
