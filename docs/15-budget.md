## 15. 予算計画

本イベントは、コミュニティ主体の取り組みとして、過度なコストをかけずに実施することを前提としています。

必要最小限の支出に抑えつつ、協賛等を通じて無理のない形で運営を行うことを目指します。

### 15-1. 想定される主な支出

本イベントでは、以下のような項目に支出が発生することを想定しています。

- 会場費（施設利用料）  
- 備品・機材費（プロジェクター・舞台・音響等の会場備品レンタル）  
- 印刷費（ポスター・チラシ等）  
- 運営関連費（消耗品・スタッフ用Tシャツ等）  

また、今後追加されるコンテンツ内容によっては、以下のような費用が発生する可能性があります。

- 技術的なサービス利用料（例：LLM API 等）  

※会場条件や協力内容により、一部費用は軽減される可能性があります

### 15-2. 想定される収入

本イベントでは、以下の収入を想定しています。

- 協賛金（企業・団体からの支援）  

本イベントは参加者からの参加費を前提とせず、誰でも参加しやすい形とすることを重視しています。

### 15-3. 懇親会の取り扱い

イベント終了後に実施予定の懇親会については、懇親会参加者から会費を徴収し、飲食費等に充てる形を想定しています。

そのため、懇親会は本イベント本体の収支とは分けて管理する予定です。

### 15-4. 収支の考え方

本イベントは営利目的ではなく、収益の最大化を目指すものではありません。

そのため、

- 必要な支出を無理なく賄う  
- 過剰な収益を生まない  
- 継続可能な形で運営する  

といったバランスを重視しています。

### 15-5. 予算規模のイメージ

本イベントは小規模なコミュニティイベントとして、比較的コンパクトな予算規模での実施を想定しています。

企業・団体の皆様が気軽に関われる水準での協賛を前提とし、無理のない範囲で運営を行います。

### 15-6. 今後の調整について

具体的な金額や内訳については、会場条件や協賛状況、コンテンツ内容の確定に応じて調整を行います。

必要に応じて予算配分の見直しを行い、現実的かつ持続可能な運営を目指します。
