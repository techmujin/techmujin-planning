## 15. 予算計画

本イベントは、コミュニティ主体の取り組みとして、過度なコストをかけずに実施することを前提としています。

営利目的ではなく、無理のない形で継続可能なイベントとして運営することを重視しており、必要最小限の支出を協賛等によって賄いながら実施する方針です。

本イベントの予算および収支は、主催団体「テック無尽」の会計として管理します。

### 15-1. 予算設計の考え方

本イベントは、収益の最大化を目的としたイベントではありません。

そのため、

- 必要な支出を無理なく賄う  
- 過剰な収益を生まない  
- 継続可能な規模で実施する  

といったバランスを重視しています。

また、参加者が気軽に参加できる場とするため、イベント本体については参加費を前提としない形を基本方針としています。

イベントの予算、支出および決算は、団体規約に基づく管理・承認手続きに従って取り扱います。

### 15-2. 想定される主な支出

本イベントでは、以下のような項目に支出が発生することを想定しています。

- 会場費（施設利用料）  
- 備品・機材費（プロジェクター・舞台・音響等の会場備品レンタル）  
- 印刷費（ポスター・チラシ等）  
- 運営関連費（消耗品・スタッフ用Tシャツ等）  

また、今後追加されるコンテンツ内容によっては、以下のような費用が発生する可能性があります。

- 技術的なサービス利用料（例：LLM API 等）  

※会場条件や協力内容により、一部費用は軽減される可能性があります

### 15-3. 想定される収入

本イベントでは、主な収入として以下を想定しています。

- 協賛金（企業・団体からの支援）  

このほか、寄付金、懇親会費等の事業に伴う収入、その他の収入が発生する場合は、団体規約に基づいて管理します。

本イベントでは、地域コミュニティとの接点づくりや活動への理解を深めていただくことを重視しており、協賛についてもその考え方に基づいて実施します。

### 15-4. 懇親会の取り扱い

イベント終了後に実施予定の懇親会については、参加者から会費を徴収し、飲食費等に充てる形を想定しています。

懇親会費は団体会計の収入として取り扱い、イベント本体の収支と区分して管理します。

資産および出納は代表または会計が管理し、必要な会計報告を行います。

### 15-5. 予算規模のイメージ

本イベントは小規模なコミュニティイベントとして、比較的コンパクトな予算規模での実施を想定しています。

企業・団体の皆様が気軽に関われる水準での協賛を前提とし、無理のない範囲で運営を行います。

### 15-6. 今後の調整について

具体的な金額や内訳については、会場条件や協賛状況、コンテンツ内容の確定に応じて調整し、団体規約に基づいて予算の決定および決算の承認を行います。

必要に応じて予算配分の見直しを行い、現実的かつ持続可能な運営を目指します。
